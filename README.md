# Mi lista

Lista de deseos con seguimiento de precios y cálculo de costo con casillero.

## Publicarla

1. Crea un repositorio público llamado `mi-lista` y sube todos estos archivos a la raíz.
2. En **Settings → Pages** elige la rama `main` y la carpeta `/ (root)`.
3. Abre en Chrome `https://tu-usuario.github.io/mi-lista/` y toca **Instalar**.

## Agregar productos desde otras apps

Con la app instalada, en Chrome o en la app de una tienda toca **Compartir** y elige **Mi lista**. Se abre el formulario con el nombre y el enlace ya llenos.

## Actualizar la app

Si cambias algún archivo, abre `sw.js` y sube el número de `VERSION` (por ejemplo, de `milista-v1` a `milista-v2`).
